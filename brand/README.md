# Okapi — brand

**Idea:** the okapi looks assembled from other animals (giraffe head, zebra
stripes, horse body). Okapi the product too: Astro + Sanity + AI. Its 35 cm
tongue reaches everywhere — like the chat, which only goes where the role
allows.

## Mark
- `okapi-mark.svg` — the face, front view: ears, ossicones, dark blaze, pale
  cheeks, striped neck and the blue tongue. Use it as is; it carries its own
  colours. Favicon: the same file (`site/okapi.svg`).
- Minimum size 24 px. Keep the tongue: it's the one place the accent lives in the mark.

## Type
- Display: **Fraunces** with `SOFT 100, WONK 1`, weights 700–900 (soft, a bit odd).
- Body: **Hanken Grotesk** 400–600. Code/labels: **JetBrains Mono**.

## Motifs
- **Stripes**: horizontal cream bands (the okapi's legs) as dividers and bullets.
- **The lick**: the tongue moves every few seconds on the landing. Nothing else animates.
- Voice: plain Spanish (rioplatense), short sentences, one okapi fact per page at most.
