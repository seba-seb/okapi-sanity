Permisos

La lengua llega lejos. Vos decidís hasta dónde.

Un archivo en tu proyecto define qué puede hacer cada rol de Sanity. El editor y el chat lo respetan: la IA nunca puede más que la persona que la usa.

9permisos: textos, imágenes, estilos, ajustes, reordenar, estructura, componentes, publicar y chat.
0claves de IA en el navegador. Viven en el hosting de cada proyecto.
1paso para deshacer todo lo que hizo el chat.
src/okapi.policy.ts
export const POLICY = {
  administrator: {
    label: "Agencia",
    can: ["text", "images", "style", "settings",
          "structure", "components", "publish", "chat"],
  },
  editor: {
    label: "Cliente",
    can: ["text", "images", "reorder", "publish", "chat"],
  },
  contributor: {
    label: "Cliente, solo borradores",
    can: ["text", "chat"],
  },
  // cualquier otro rol: solo mirar
  default: { label: "Lectura", can: [] },
};

Instalar

Se lo pedís a tu agente.

La instalación está escrita para que la siga cualquier agente de código, paso a paso, sin pisar tus archivos.

  1. Pedíselo

    Pegá el prompt de arriba. El agente detecta si el proyecto es nuevo o existente y te pregunta lo que falta.

  2. Conectá Sanity

    Creás el proyecto, iniciás sesión una vez y el editor queda en /studio#/editor.

  3. Dale una lengua

    Cargás la clave de IA en el hosting (ANTHROPIC_API_KEY u otra) y el chat aparece para quien tenga permiso.

Preguntas

¿Funciona con un proyecto Astro que ya tengo?

Sí. Tus páginas, tu layout y tu configuración quedan como están. Okapi suma sus carpetas y sirve las páginas del editor en las rutas que elijas. Lo probamos sobre el template de blog oficial de Astro sin tocar una línea del blog.

¿Quién paga la IA?

Cada proyecto usa su propia clave, guardada en las variables de entorno del hosting. Nunca llega al navegador. La agencia puede limitar qué modelos aparecen en el chat.

¿Es un Webflow?

Se le parece en la forma de editar, pero no hay CSS libre: todo se estila con los tokens de tu diseño. Los bloques nuevos se escriben en código y el editor los compone. Así el cliente no puede romper la marca.

¿Necesito saber Sanity?

No para usarlo. Sanity guarda el contenido y maneja los usuarios; el día a día pasa en el editor. Para extenderlo, las reglas están en AGENTS.md y tu agente las lee solo.

¿Por qué un okapi?

Porque parece armado con partes de otros animales, como este proyecto. Y porque tiene una lengua de 35 centímetros con la que se limpia las orejas, que nos pareció la mejor metáfora posible para una IA con permisos.
